# AI-Based Resume Analyzer & Skill Enhancement

An AI-powered resume analysis system built with Python and Flask that analyzes resumes, extracts skills, calculates ATS scores, identifies skill gaps, and recommends suitable job roles based on the candidate's skills.

## 🚀 Features

- 📄 Upload resumes in PDF and DOCX formats
- 🤖 Analyze resume content using NLP techniques
- 🧠 Extract technical and relevant skills
- 📊 Calculate ATS score based on selected job requirements
- 🎯 Identify missing skills for a selected job role
- 💼 Recommend suitable job roles
- 📈 Display skill-match percentages
- 📧 Extract basic candidate contact information
- 🌐 Simple web-based interface using Flask

## 🛠️ Technologies Used

- **Python**
- **Flask**
- **Pandas**
- **NumPy**
- **Scikit-learn**
- **PyPDF2**
- **python-docx**
- **NLTK**
- **TextBlob**
